# Trafikskolan – demo av teoriprov

Fristående demo av elevappen och adminappen. All data ligger i webbläsaren.

**Öppna demon:** https://rafidnoel-spec.github.io/trafickskola_demo/

- Elevappen: välj körkortstyp → språk → pärm, svara, flagga och se resultat.
- Adminappen: logga in med `admin` / `admin123`.

Detta repo innehåller bara den byggda demon. Källkoden finns i det privata repot `trafick_skolan`.
